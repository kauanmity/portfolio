## Desenvolvimento

Abra `index.html` no navegador. O site usa HTML, CSS e JavaScript e pode ser editado sem instalar dependências.

Os projetos e competências ficam em `index.html`. Os estilos ficam em `styles.css` e os filtros em `portfolio.js`. O GitHub Pages publica a raiz da branch `main`.
